# 🌸 Открой меня

Одностраничный сюрприз: кнопка **«Открой меня»** → ливень из цветов → пазл из ваших
фотографий → музыка из Spotify → открытка с письмом.

Всё в одном файле `index.html`. Ни сборки, ни зависимостей, ни интернета для цветов —
каждый цветок рисуется вектором прямо в браузере, поэтому все они разные.

## Как открыть

Просто дважды кликнуть по `index.html`.

Если хочешь, чтобы работали фото из папки `photos/` — нужен локальный сервер
(браузер не отдаёт локальные файлы со страницы, открытой как `file://`):

```bash
python3 -m http.server 8000
# затем открой http://localhost:8000
```

## Что настроить под себя

Всё в начале `<script>` в `index.html`, в блоке `CONFIG`:

| Что | Как |
|---|---|
| **Песня** | `CONFIG.spotify` — вставь ID трека или плейлиста. Берётся из ссылки: `open.spotify.com/track/`**`0tgVpDi06...`**. Для плейлиста поставь `type: 'playlist'`. |
| **Фото для пазла** | Положи `1.jpg`, `2.jpg`, `3.jpg` в папку `photos/`. Список и количество — в `CONFIG.photos`. |
| **Текст письма** | `CONFIG.letter` — массив, каждая строка = абзац. Подпись — `CONFIG.signature`. |

Фото можно и не класть заранее: на экране пазла есть кнопка
**«Загрузить свои фото»** — выбираешь картинки прямо в браузере, они никуда не
отправляются, всё остаётся на устройстве.

Квадратные фото смотрятся лучше всего.

## Как это устроено

- `buildFlower()` — генератор цветов: 6 форм (пион, роза, анемона, циния, сакура,
  ранункулюс), случайные палитры, число и разворот лепестков. Повторов практически не бывает.
- Пазл — сетка 3×3, плитки меняются местами по нажатию. Когда всё сходится,
  поверх проявляется цельная фотография.
- Открытка — SVG-конверт с клапаном на 3D-повороте, письмо печатается по буквам.

Работает на телефоне, поддерживает `prefers-reduced-motion`.
