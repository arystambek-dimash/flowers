# Сюда кладём наши фото

Положи файлы с именами `1.jpg`, `2.jpg`, `3.jpg` (квадратные — лучше всего).

Если файлов нет — на странице автоматически покажутся красивые заглушки,
а фото можно подгрузить прямо в браузере кнопкой **«Загрузить свои фото»**.

Чтобы поменять список/количество — правь `CONFIG.photos` в `index.html`.
